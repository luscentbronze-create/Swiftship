# Primeway Express - Customer Tracking Portal

A high-performance shipment tracking portal built with React, TypeScript, Tailwind CSS, Vite, and Supabase.

## Features
- Real-time milestone tracking for 11-character alphanumeric codes
- Resilient multi-tiered fallback architecture (Direct DB queries, RPC functions, and offline data)
- Dynamic visibility controls for customer privacy (protecting sender/receiver contact information and cargo details)
- Package Weight & Dimensions (L × W) conditional rendering
- Guaranteed landing on Home view upon refresh or initial visit
